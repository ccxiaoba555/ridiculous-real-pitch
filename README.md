A tiny deterministic program that writes one startup pitch to `/output/entry.txt`: a dog-walking service for people who don't own a dog — rent a stranger's dog by the hour, get the walk and the cuddles, then hand the leash back; the owner gets a walked dog, you skip the vet bills. One sentence, 199 characters, absurd at first glance, real by the second.

## Run it

```sh
python3 main.py
```

The program validates the pitch against the gate (1–200 characters, a single sentence of UTF-8 text, not blank) and writes it to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`).
